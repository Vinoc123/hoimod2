# hoimod2

Мод для Hearts of Iron IV 1.16. Лагеря Германии и мирная конференция без капитуляции.

## Как включить

В лаунчере отметьте мод `hoimod2`. Игре нужен файл в каталоге модов с путём к этой папке. На этой машине он создаётся локально и в Git не входит, потому что путь абсолютный.

На другой машине создайте `mod/hoimod2.mod` в каталоге документов Hearts of Iron IV:

```
name="hoimod2"
version="1.0"
tags={
	"Gameplay"
	"Balance"
}
supported_version="1.16.*"
path="/полный/путь/к/hoimod2"
```

`descriptor.mod` в репозитории пути не содержит.
